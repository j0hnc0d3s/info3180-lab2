# INFO3180 — Lab 2

> Flask forms with WTForms validation and CSRF protection.

Built for **INFO3180 — Web Programming II** at the University of the West Indies, Mona.

## Tech Stack
- **Backend:** Python (Flask), Flask-WTF, WTForms
- **Templating:** Jinja2
- **Frontend:** HTML5, CSS3

## Topics Practiced
- Flask-WTF form definitions
- Server-side validation with WTForms validators
- CSRF protection in form submission
- Flash messages for user feedback
- File upload handling

## Run Locally
```bash
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
flask run
```
